# ChrionML AI Labs

Scientific AI and real estate forecasting website for https://daramoladoes.github.io/.

## Upload to GitHub Pages

1. Extract this ZIP on your computer.
2. Open https://github.com/DaramolaDoes/DaramolaDoes.github.io.
3. In Settings → Pages, identify the current publishing branch and folder. Keep the existing deployment configuration.
4. Open that branch and folder in the Code tab. Choose Add file → Upload files.
5. Upload the extracted files and the assets folder directly into the publishing folder, keeping assets/cml-logo.png at that exact path. Do not upload the enclosing ZIP or place the files in an extra subfolder.
6. Commit the change and check the existing Pages deployment in Actions.
7. Verify /, /research.html, /standings.html, /schedule.html, and /boxscore.html.

Keep unrelated repository assets, CNAME, and workflow files. The package replaces the matching HTML files and README only when you upload them. No new workflow is included because the repository’s current configuration was not inspected. No build or npm installation is required.

## Pages

- index.html: light homepage with equal prominence for scientific AI and real estate forecasting.
- research.html: research frameworks and links to the city-tour pages.
- standings.html: 64 locations across four supplied regional seed lists.
- schedule.html: 32 proposed regional 1–16 through 8–9 matchups. Dates and pairing confirmation remain pending.
- boxscore.html: Cambridge–Ithaca ten-measure comparison. Results and Ithaca ZIP are pending. Property-type control changes labels only.

All pages share the CML© logo and navigation, including https://www.youtube.com/@chrionml/videos. Logo is assets/cml-logo.png. Preview banners are removed. Titles, canonical links, metadata, favicon, sitemap, and indexing directives are included.
