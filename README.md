# ChrionML® Week 4 consolidated release

This is a complete replacement static-site package, including the updated index.html. Extract the ZIP and upload its contents to the repository root; retain the directory structure and .nojekyll. Do not upload a containing directory or the ZIP itself as the site.

Week 4 uses 81 monthly observations for Brooklyn and Philadelphia, through September 2026, to forecast October 2026. Reproduction code, source CSVs, environment versions, full-precision model results and validation evidence are included. Weeks 1–3 retain their published September forecasts; their original model fits were not rerun in this revision.

Read DEPLOYMENT.md, RELEASE-NOTES.md and VALIDATION.md. The interactive Boston/Providence ridge experiment remains separate from the archived matchup forecasts.
