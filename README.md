# ChrionML® Interactive Lab production add-on

A polished, additive product experience for the existing ChrionML® research site.

**Open `intelligence-lab.html`** for the product landing page and **`forecast-lab.html`** for an executable model with market dropdowns, training-window controls, regularization, baseline comparison, chart and forecast table.

The dataset files contain 80 monthly observations per city transcribed from the user's uploaded CSVs. The forecasting page embeds these values to work without a server or cross-origin fetch; the CSVs are provided for transparent download.

Read `DEPLOYMENT.md` before uploading. **Do not replace existing `index.html`.** `HOMEPAGE-INSERT.html` contains the isolated section to paste into the existing homepage.
