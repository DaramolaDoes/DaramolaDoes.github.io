Evaluation protocol

Make the comparison reproducible.

Data definition and scope

Use the same property type, ZHVI series variant, monthly window, data cutoff, and forecast horizon for both ZIP codes. Cambridge uses 02139; the Ithaca ZIP code still needs selection. Confirm each series exists and has adequate coverage. Report actual usable months rather than assuming N = 60.

Historical statistics

For observed values y₁ through yₙ: average = sum(y) / N; high = max(y); low = min(y). Year-over-year change = 100 × (yₜ / yₜ₋₁₂ − 1). High and low describe monthly index values, not individual homes.

Forecast and backtest

Evaluate one-month-ahead predictions with chronological rolling origins. Fit and tune using only information available before each prediction. Compare against a last-observed-value forecast over identical test months. MAE = mean absolute forecast error in dollars. Disclose test count, dates, series vintage, and revisions.

Uncertainty and matchup outcome

Estimate an 80% prediction interval and assess its coverage in backtesting. Do not imply guaranteed coverage. After the next observation arrives, compare absolute errors and error relative to each location’s baseline. A higher home value or larger predicted increase does not establish forecast superiority. Ties and inconclusive results should remain possible.
