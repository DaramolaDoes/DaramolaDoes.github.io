# GitHub Pages deployment — 64-City Price Bracket

This package is ready for the repository root of `DaramolaDoes/DaramolaDoes.github.io`.

## Upload through GitHub

1. Download and extract `ChrionML-64-City-Price-Bracket-Production.zip`.
2. Open `https://github.com/DaramolaDoes/DaramolaDoes.github.io`.
3. Select **Add file → Upload files**.
4. Upload the extracted files and folders—not the ZIP or its enclosing folder—to the repository root.
5. Confirm that `assets/cml-logo.png` remains inside the `assets` folder.
6. Allow GitHub to replace matching files. `schedule.html` retains its existing schedule experience.
7. Commit with: `Add 64-city price bracket with automatic winner advancement`.
8. Wait for the GitHub Pages workflow to complete under **Actions**.
