# Deploy the consolidated Week 4 release

1. Back up the current GitHub repository and record its commit before changing files.
2. Extract this ZIP. Upload all extracted contents to the root of DaramolaDoes.github.io, replacing corresponding files, including index.html. Preserve assets/, research/, reproducibility/ and .nojekyll. This supersedes older add-on-only deployment instructions.
3. Commit and wait for GitHub Pages to finish its deployment.
4. Open the homepage, Week 4 study, Week 4 box score, research archive, standings, schedule, bracket and forecast lab. Check the published date, target months, navigation and source-data links against VALIDATION.md.
5. If deployment introduces a regression, revert that deployment commit.

This package does not publish itself. GitHub Pages response behavior must still be checked after deployment.
