# GitHub Pages Deployment

Repository: `DaramolaDoes/DaramolaDoes.github.io`

## Upload through GitHub

1. Download and extract `ChrionML-Week3-Production-2026-10-09.zip`.
2. Open the repository on GitHub and select **Add file → Upload files**.
3. Upload the **contents inside the extracted folder** to the repository root. Do not upload the ZIP itself or an enclosing folder.
4. Allow replacement of existing files and include all new Week 3 files and folders.
5. Commit directly to the production branch used by GitHub Pages.
6. Suggested commit message: `Publish Week 3 Back Bay vs Hanover research`
7. Wait several minutes, then hard-refresh the production site.
